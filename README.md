# Космо-Старт · Видео

Страница с интро и видеофонами форума-конкурса «Космо-Старт». Ролики встроены с BoomStream, исходники — на [Яндекс.Диске](https://disk.yandex.ru/d/Zu5KEFCQ8cObfg).

Страница: https://baslie.github.io/kosmo-start-videos/

Чистые HTML, CSS и JS без сборки. Чтобы добавить ролик, скопируйте блок `<article class="clip">` в `index.html`, поменяйте код BoomStream и добавьте строку `config.jsonp` с этим кодом внизу страницы.
