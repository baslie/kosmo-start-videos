## Как добавить ролик

Сайт собран на чистых HTML, CSS и JS, без сборки. Скопируйте блок `<article class="clip">` в `index.html`, поменяйте в нём код BoomStream и добавьте внизу страницы строку `config.jsonp?color=false&title=0` с тем же кодом.
